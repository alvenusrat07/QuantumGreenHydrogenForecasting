Welcome to Our Project

Project Overview

This project simulates a quantum-inspired green hydrogen production forecasting system using classical ESP32 microcontroller logic. The forecasting function mimics quantum-like superposition by assigning probabilistic weights to possible outcomes: an increase, maintenance, or decrease in hydrogen output. Our goal is to explore how these concepts can be applied to sustainable energy management.

Methodology

Simulation Architecture:
  • Solar Input (): LDR sensor to simulate light intensity.
  • Water Input (): Potentiometer to simulate electrolyzer water flow or level.
  • Central Processing (): ESP32 module responsible for the quantum-inspired forecasting logic.
  • Forecasting Output (): LEDs visually indicate predicted hydrogen production levels (color and brightness).
  • Data Logging (): Serial Monitor for detailed analysis of inputs, states, and results.

System Architecture

Our final system implements a hybrid simulation architecture. It combines real-world sensor data with digitally generated patterns to create a robust testing environment for the quantum-inspired algorithm.

System Components & Data Flow:
  • Hybrid Inputs: Weighted mix of real-world LDR sensor data and digitally generated sine wave patterns.
  • Central Processing Unit: ESP32 runs the quantum-inspired probabilistic forecasting algorithm with memory weight stabilization.
  • Dual-OLED Visualization (HMI): Real-time status monitor and live trend analysis graphs.
  • Forecast Indicator: RGB LED provides immediate visual feedback (Green=Increase, Blue=Stable, Red=Decrease).
  • Data Logging: CSV-formatted data output for external analysis.

Results & Demonstration

The final system successfully demonstrates the capability of the quantum-inspired algorithm to process hybrid inputs and generate stable, probabilistic forecasts. The dual-OLED setup provides a comprehensive Human-Machine Interface (HMI) for real-time monitoring.

Key Algorithm Features

  • Quantum-Inspired Probabilistic Forecasting: Calculates probabilities for three superpositioned states and collapses them to a single decision, mimicking quantum measurement uncertainty.
  • Memory Weight Stabilization: Adds weight to previous decisions to prevent erratic switching and introduce realistic system inertia.
  • Hybrid Data Fusion: Intelligently combines real-time sensor readings with generated data patterns for robust testing.
